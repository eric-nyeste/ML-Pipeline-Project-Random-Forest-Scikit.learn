# Random Forest Classification of Single-Cell Gene Expression
 Applied Python, scikit-learn and Random Forest classification to a gene-expression dataset; investigated prediction, feature selection and model evaluation in a supervised-learning assignment.
This study investigates the application of Random Forest classification to single-cell gene-expression data, emphasizing model evaluation, feature selection, and the methodological tradeoffs between predictive performance and model complexity. Using a dataset of 871 neuronal nuclei represented by 608 gene-expression features, the experiment evaluates binary classification of the e1 excitatory neuron cluster against non-e1 observations. Six Random Forest configurations were compared using out-of-bag (OOB) estimation, followed by manually implemented stratified three-fold cross-validation and Gini-based feature-importance analysis.

The highest-performing configuration, employing 100 trees and square-root feature sampling, achieved 99.66% OOB accuracy and 99.54% mean cross-validation accuracy. Subsequent experiments evaluated whether reduced feature sets could preserve classification performance. A six-gene classifier achieved 99.08% mean cross-validation accuracy, demonstrating substantial dimensionality reduction at the cost of increased false-negative classifications. Feature selection was performed independently within each cross-validation training fold to prevent evaluation-data leakage.

The study also documents the use of generative AI as an instructional and computational collaborator in experimental design, Python implementation, debugging, and interpretation. Findings illustrate both the practical capabilities and methodological limitations of supervised classification, while examining the role of human judgment in AI-assisted scientific inquiry.

**Keywords:** Random Forest; supervised machine learning; gene-expression classification; feature selection; cross-validation; model evaluation; human–AI collaboration.
